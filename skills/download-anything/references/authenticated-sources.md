# Authenticated and browser-resolved sources

Use only the account, item and access scope the user authorized. Reuse valid permission already given for that same task; do not ask again simply because the transfer changes tools. A login-required error is not permission to export a whole browser profile or collect session cookies.

Open the exact requested item using the host's supported browser/connector. Confirm the file or media identity and use its documented download/export capability first. Reading a tool's current documentation matters: do not invent page-asset export methods or promise a connector can download bytes when it only returns metadata.

For stories or other sequential viewers, avoid advancing into unrelated items and pause the requested media when supported. Explain account-visible effects such as a recorded view before causing them. Do not interact with messages, reactions or follow controls.

If the supported export fails but the browser exposes an exact authorized media URL, a bounded transfer may be appropriate. Match the asset to the selected item, not merely the first preloaded video. Keep signed URLs and tokens transient and out of logs/reports. Do not reuse them for other items. For range-based responses, establish a complete file before claiming success; removing observed range parameters is only appropriate when the same authorized source supports a complete response.

Blob/MSE playback can involve separate audio/video tracks and may lack a supported download route. Use only observable authorized sources, merge where needed and verify the final streams, duration and a representative frame. Report unsupported extraction instead of bypassing DRM or access controls.

If credential handling is necessary, use the host's protected supported mechanism and the requested account scope. Never ask the user to paste passwords, cookies or tokens into chat. Close task-created temporary tabs after verification when safe; do not close existing user tabs.

Downloading private content does not authorize sharing it. Report only saved paths, file properties and completion state, not private source URLs or unnecessary account identifiers.
